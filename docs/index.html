TunerToolPro

A Linux desktop tool for GM 4L60E and 6L80E transmission calibration work. It calculates; it never writes to a vehicle.

Read before use. Check every value against your vehicle, converter, cooler and a road test before it goes into a controller. You use this tool at your own risk.

Requirements

  • Linux with a desktop. Tested on Zorin OS 18.1 (Ubuntu 24.04 base).
  • Python 3.10 or newer, with Tkinter and venv for the installer: 
    sudo apt install python3-tk python3-venv git
  • An internet connection for the first install (PyQt6 and pandas are downloaded).

Install

  1. Download the code: 
    git clone -b claude/keen-hawking-ite6nw https://github.com/nbrookes80-spec/noddy.git
cd noddy/"General Motors/Linux-Tuning-Suite"
  2. Run the Setup wizard: 
    python3 installer/install_tunertoolpro.py
  3. Follow the pages (Welcome, Terms, Install folder, Options, Ready, Installing, Completed). Enabling the AI Assistant is optional and needs an Anthropic API key.
  4. Start it from the applications menu, or type tunertoolpro in a terminal.

Uninstall

Choose Uninstall TunerToolPro from the applications menu. Your settings are kept unless you tick the box to delete them.

What it does

  • Shift Points: upshift, downshift and TCC speeds; TPS x Gear export for VCM Editor or TunerPro; Bluecat .BTC tunes.
  • Vehicle: vehicle profile, consistency checks, and import of EFILive calibration or comparison CSV exports.
  • Pressure & Timing, Dyno & Drag, Datalog, XDF / BIN, BCT Tunes.
  • AI Assistant (optional): proposes changes; a change applies only when you press Apply.

It does not connect to a vehicle, does not read HP Tuners encrypted files, and does not read EFILive .calz, .ctz or .log files yet.
