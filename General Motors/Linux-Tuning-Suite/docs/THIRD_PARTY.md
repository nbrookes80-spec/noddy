## SavvyCAN (Sniffer logic)

The CAN Sniffer in TunerToolPro (`app/tunertoolpro/canbus/sniffer.py`, and the Sniffer tab and screen built
on it) is a Python port of the Sniffer window in SavvyCAN: the per-ID change tracking, the increment and
decrement colouring, notching and un-notching, muting notched bits, fading inactive bytes, the bit view and
the ID expiry. The idea and the behaviour are theirs; the code here is a fresh implementation.
