# T43 / 6L80E reference

Imported into the main repo under `General Motors` from `nbrookes80-spec/t43-6l80e-reference`.

This folder contains the third-party reference material collected for tuning and rebuilding the 6L80E / T43 in GM applications, with the original source structure preserved as closely as possible.

## Included references

- `6l80-rebuild-guide/` — offline 6L80 rebuild / teardown / troubleshooting guide
- `caprice-ppv-can-database/` — CAN message database and DBC for the GM E38 / 6L80E / T43 platform

## Upstream attribution

- `6l80-rebuild-guide/` source: `https://github.com/chhall91/6l80-rebuild-guide`
- `caprice-ppv-can-database/` source: `https://github.com/aisom02/caprice-ppv-can-database`

This is a reference archive only, not verified tune data. The original upstream material should be consulted against the vehicle service manual / ATSG information where applicable.
