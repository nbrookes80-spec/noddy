# 6L80 Rebuild Guide

Offline shop reference web app for GM 6L80 (RPO MYC) teardown, rebuild and troubleshooting.
Plain HTML/CSS/JS, no build step. Open `index.html` directly or use the GitHub Pages site; installable to the iPhone home screen and works offline after first load.

**Verify all specs against the GM service manual / ATSG manual for the specific model year.** Diagrams are simplified schematics, not factory drawings. See the in-app Sources page.
