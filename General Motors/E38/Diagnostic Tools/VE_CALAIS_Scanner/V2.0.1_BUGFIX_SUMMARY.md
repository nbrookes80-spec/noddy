## What was actually wrong

The V2.0.0 APK I handed you had **no compiled code in it**. It built "successfully" by Gradle's own report, but the final packaging step silently produced an APK with **zero `classes.dex` files** — a shell with resources and a manifest but no app logic. That's why:

- It showed a blank screen in Android Studio (there was nothing to run)
- It wouldn't install on your phone: `INSTALL_FAILED_INVALID_APK: ... code is missing`
- It was much smaller than earlier builds (1.45 MB vs the correct 7.28 MB)

**Root cause:** when I deleted the `.gradle` cache and upgraded the Gradle wrapper (8.9 → 8.10.2) in the same session, Gradle's incremental build state got corrupted — the dex-merge tasks reported `UP-TO-DATE` and reused stale (empty) intermediates instead of actually re-running. I trusted "BUILD SUCCESSFUL" without checking the APK's actual contents. That was the mistake — noted so it doesn't happen again.

## What I fixed

1. Stopped all Gradle daemons and deleted `.gradle`, `app/build`, `build` completely (not just `.gradle`)
2. Rebuilt with `--no-build-cache` from a completely clean state — **all 39 tasks executed fresh**, none reused
3. Verified the resulting APK directly: `unzip -l app-debug.apk | grep dex` → 6 dex files present, 7.28 MB total

## Second bug found during verification: button text wrapping

While confirming the UI on your actual phone, the Home screen's "Live Data / Scanner / Sniffer" buttons were wrapping one character per line. Cause: those buttons used the old Material Components v2 style (`Widget.MaterialComponents.Button.OutlinedButton`) while the app's theme is Material 3 (`Theme.Material3.DayNight.NoActionBar`). Mixing the two breaks attribute resolution and blows out the button's default padding/min-width.

**Fixed:** switched all 11 occurrences (across `fragment_home.xml`, `fragment_live_data.xml`, `fragment_pid_scanner.xml`, `dialog_quick_menu.xml`, `fragment_sniffer.xml`) to `Widget.Material3.Button.OutlinedButton`, plus explicit compact sizing (smaller text, minimal padding/insets) on the 3-across and 2-across button rows so they fit properly on a phone-width screen.
